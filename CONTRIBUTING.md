# Contributing


Thanks for your interest in contributing! Here’s how to get started:

## 🚀 Quick Start

1. **Fork the Repository**

- Navigate to https://github.com/mihaimoga/sbom.ro.
- Click Fork to create your copy.

2. **Clone Your Fork**

```bash
git clone https://github.com/<your-username>/sbom.ro.git
cd sbom.ro
```
3. **Create a Branch**

Use a descriptive branch name:
```bash
git checkout -b feature/<description>
```

## ✅ Guidelines

- Match existing code style.
- Use clear commit messages (e.g., feat: add IPv6 support).
- Add/update tests for new features.
- Update docs if needed.

## 🔍 Issues & PRs

- Check https://github.com/mihaimoga/sbom.ro/issues before creating new ones.
- Keep PRs focused and descriptive. Reference issues (e.g., Closes #123).

## 💬 Communication
For questions, use https://github.com/mihaimoga/sbom.ro/discussions or comment on relevant issues.

## ❤️ Thank You!
Your contributions make **sbom.ro** better for everyone!
