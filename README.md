# sbom.ro

[sbom.ro](https://www.sbom.ro/)

## 🌐 Features

- Instantly shows your public IP address.
- Lightweight and fast-loading interface.
- Useful for network configuration and connectivity checks.

## 🚀 Installation
Clone the repository:
```
git clone https://github.com/mihaimoga/sbom.ro.git
```
Navigate to the project folder and open index.php in your browser.

## 🛠 Tech Stack

- HTML5 / CSS3
- JavaScript
